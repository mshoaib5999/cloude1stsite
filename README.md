# ⚡ Muhammad Shoaib Asghar — Portfolio Website

A modern, high-performance dark portfolio landing page for **Muhammad Shoaib Asghar** (Senior WordPress Developer & WooCommerce Architect), engineered with **React**, **Vite**, **TypeScript**, **Tailwind CSS**, **GSAP**, **Framer Motion**, and **hls.js**.

---

## ✨ Key Features & Sections

- **⚡ Custom Loading Screen**: 2700ms `requestAnimationFrame` progress counter (`000` → `100`) with dynamic word transition (`Design`, `Create`, `Optimize`, `Scale`) and golden amber accent glow.
- **🎥 Dynamic Hero Section**: Background HLS streaming video player powered by `hls.js`, profile avatar spotlight with glowing amber rim light, cycling titles, and smooth CTA buttons.
- **💼 Selected Works Bento Grid**: Interactive project cards showcasing 6 key projects from experience (`RossAi`, `Lumora Nutrition`, `AION Dubai`, `Flip My Life`, `Creative Contracting`, `Vice Pharmaceuticals`) with live metric badges and detail modal view.
- **🛠️ Capabilities & Services**: Custom WP Theme Development, WooCommerce & Payment Integration, Core Web Vitals Optimization, and ACF Pro Data Architecture.
- **📝 Technical Journal**: Article highlights covering speed optimization, headless WP vs custom themes, and security.
- **🎯 Visual Playground**: Parallax exploration gallery with lightbox preview.
- **📜 Professional Experience Timeline**: Interactive career trajectory across agencies and university background.
- **📊 Key Metrics Grid**: 3.5+ Years Experience • 400+ Websites Delivered • 100/100 Core Web Vitals.
- **💬 Contact & Footer**: Vertically inverted HLS background video, GSAP marquee banner, email copy action, and direct social links.

---

## 🛠️ Technology Stack

- **Framework**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS + Custom CSS Variables & Animations
- **Animations**: GSAP + Framer Motion
- **Video Player**: Hls.js
- **Icons**: Lucide React / Inline SVG

## 🚀 Quick Start (Local Setup)

1. **Clone the repository**:
   ```bash
   git clone https://github.com/your-username/shoaib-portfolio.git
   cd shoaib-portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
